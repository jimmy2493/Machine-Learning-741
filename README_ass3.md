# Assignment 3

Option 4: Time Series Forecasting using Recurrent Neural Networks.

## Structure

Place the notebook and datasets in the same directory, or place the datasets inside a `data/` directory:

```text
Assignment3/
├── src/
│   ├── ass3.ipynb
├──── data/
│   |   ├── Metro_Interstate_Traffic_Volume.csv
│   |   ├── household_power_consumption.txt
│   |   ├── PRSA_Data_Wanliu_20130301-20170228.csv
│   |   ├──  energydata_complete.csv
│   |   └── hour.csv
├──── results/  # created automatically
└── README.md
```

The notebook also accepts the supplied `(1)` filename variants.

## Running

Open `ass3.ipynb` and run all cells from top to bottom. The notebook performs the complete experiment and saves the main tables and figures to `results/`.
